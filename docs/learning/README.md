# Learning notes

Each topic uses the same template. Files are generated from `scripts/topic_catalog*.py` into `docs/learning/P*/`.

Expand a note **when you study it**. Do not treat generation as completion.

Template:

1. What is it?
2. Why do we need it?
3. How does it work?
4. Example in our project (synthetic Atlas only)
5. What must we learn?
6. Hands-on exercise
7. Definition of Done
8. Resources (official links)
9. Key Takeaways (max five)
10. Related Topics
