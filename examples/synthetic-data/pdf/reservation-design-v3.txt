This document is the approved design for inventory reservation in the fictional Atlas Inventory Platform.

[Page 2]
A reservation binds stock to a checkout session. It is not a completed order.

[Page 3]
Data movement: API POST /reservations -> reservation table -> Kafka topic inventory.reserved.

[Page 4]
